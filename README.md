# univoice-shared

Спільні файли для всіх сторінок сайту Univoice (Tilda): меню, «Налаштування» (ім'я, прізвище, підпис), діалоги, кнопки, попапи, загальні стилі та Хрономір.

| Файл | Що в ньому |
|---|---|
| `univoice-ui.css` | Кольори, база, меню, поля, кнопки, попапи, діалоги, налаштування й підпис, загальний адаптив |
| `univoice-ui.js` | Вставляє меню, попап «Налаштування» з підписом і діалоги; дає сторінкам `window.Univoice` |
| `univoice-speech.js` | Хрономір: перетворює числа, дати, час, суми, відсотки, телефони, одиниці, скорочення й абревіатури на слова та рахує час прочитання за звуками й паузами; дає сторінкам `window.UnivoiceSpeech` |
| `tests/speech.test.js` | Перевірки Хрономіра (`node tests/speech.test.js`) |

Репозиторій публічний, бо сайт завантажує ці файли через jsDelivr. Тут немає паролів чи особистих даних: ім'я та підпис диктора зберігаються лише в його браузері.

## Як підключити на сторінці

У CSS-блоці сторінки (перед `<style>` сторінки):

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/univoiceua-collab/univoice-shared@<ВЕРСІЯ>/univoice-ui.css">
<script src="https://cdn.jsdelivr.net/gh/univoiceua-collab/univoice-shared@<ВЕРСІЯ>/univoice-ui.js"></script>
```

На початку HTML-блоку сторінки — місце для меню:

```html
<div data-vo-menu></div>
```

У скрипті сторінки спільні функції беруться так:

```js
const { on, onAll, show, escapeHtml, formatDate, lsGet, lsSet, LS_KEYS, getDictor, setModal, updateScrollLock, voAlert, voConfirm } = window.Univoice;
Univoice.onSettingsSaved(() => { /* напр. оновити підпис у рахунку */ });
```

## Хрономір (univoice-speech.js)

Підключається третім рядком лише там, де потрібен (зараз — калькулятор):

```html
<script src="https://cdn.jsdelivr.net/gh/univoiceua-collab/univoice-shared@<ВЕРСІЯ>/univoice-speech.js"></script>
```

```js
const r = UnivoiceSpeech.analyze(text);
// r.seconds — час прочитання (сек), r.words — слова, які прозвучать, r.pauses — паузи,
// r.spoken — текст так, як його прочитає диктор, r.hasSpeech — чи є що озвучувати
UnivoiceSpeech.normalize('Акція до 12.05.2024'); // "Акція до дванадцятого травня дві тисячі двадцять четвертого року"
```

Темп і довжина пауз — у `CONFIG` на початку файлу. Темп підібрано так, щоб звичайний текст без чисел у середньому звучав стільки ж, скільки в попередній формулі калькулятора (слова ÷ 1,9 + 0,3 сек на розділовий знак).

`<ВЕРСІЯ>` — код коміту (40 символів), у якому лежить потрібна версія файлів. Актуальні рядки підключення — у файлі [VERSIONS.md](VERSIONS.md).

## Як оновлювати

1. Змінити файли й зробити коміт.
2. Дописати в `VERSIONS.md` новий рядок: номер версії, код коміту, що змінилося.
3. На сторінках у Tilda замінити код після `@` на новий.

Кожна версія за своїм кодом доступна назавжди і ніколи не змінюється, тож будь-яку сторінку можна повернути на попередній код.

## Пункти меню

Список — на початку `univoice-ui.js` (`MENU`). Порожній `href` = пункт прихований. Поточна сторінка підсвічується сама за адресою (`/calculator`, `/stress`).
